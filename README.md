# 有度 · 资产配置工作台

中文交互式资产配置工具：填写家庭资产负债、收支、资金目标和风险边界，比较资产类别情景，调整压力假设，并通过原文检索问答理解配置依据。

## 运行

需要 Node.js 22 或更新版本。应用使用 Node 内置模块，不需要安装 npm 依赖。

```sh
npm start
```

打开终端显示的 `http://127.0.0.1:8317`。端口可通过 `PORT` 设置。服务默认只监听本机回环地址，适合个人本地使用。

```sh
npm run check
npm test
```

## 操作流程

1. 填写家庭底账，或选择四个自编虚构样例之一。未知字段保留空白，没有该项目时明确填 0。
2. 设置应急储备与每项目标金额、期限，区分现金、可变现持仓、房产和锁定资产。
3. 分别确认收入稳定性、收入与市场关联、投资经历、资金期限与损失意愿。
4. 比较三种配置情景；调整收入下降、持续月份与资产跌幅，查看现金缺口、目标资金衔接和敏感性。
5. 设置再平衡检查阈值、填写复核日期与理由，记录计划版本。通过导出/导入保存规划。

家庭金额在浏览器内计算。普通问答只发送主动填写的问题与检索片段；页面会说明主动分享规划摘要的动作。应用不写入家庭数据、问题正文或模型回答日志。

## 资料问答

问答遵循“检索原文与邻段 → 核对来源及说话人 → 模型回答 → 校验引用”的路径。DeepSeek Flash 使用兼容 OpenAI 的 Chat Completions 接口。配置写入仓库外的私有环境文件，或设置到服务端进程环境。

```sh
node --env-file=/absolute/path/to/private/model.env server.mjs
```

可参考 [环境变量样例](.env.example)、[模型说明](docs/MODEL.md) 和 [检索说明](docs/RETRIEVAL.md)。界面与健康接口区分已配置、实际联通、回答验证及降级状态。计算功能可独立使用。

原文检索连接使用者自行持有的 qizhulou 本地资料库，限定 `corpus=qizhulou`，以只读方式调用既有索引。仓库只发布软件、来源索引、开发者整理的简要参考说明和合成样例。知识库正文需自行合法取得。

助手属于独立开发的研究工具，不代表大卫翁本人或其授权服务。资料中的嘉宾观点、个人案例、历史语境与软件推演分别标注。

## 计算口径

全部金额以整数分核算；不足一分的组合分配采用余数分配，确保总额一致。

- 必要支出不含月供；月供与一年内额外到期本金分别计入。
- 36 个月内目标全额预留，应急月数由使用者填写；这是本工具的软件示例规则。
- 房产和锁定资产进入资产负债表，不进入当前可调配资金。
- 三种组合分别经过期限、现金流、偿债、经验和收入关联约束，再与损失意愿比较。压力结果不是最大亏损保证。
- 目标检查假设当前月结余不变、投资收益为零；不提供长期回报预测。

详见 [完整计算说明](docs/CALCULATION.md)。具体产品的到账、费用、税务和合同条款不在计算范围内。

## 项目结构

| 路径                                       | 用途                                 |
| ------------------------------------------ | ------------------------------------ |
| `public/`                                  | 中文响应式界面、表单、情景比较与问答 |
| `lib/allocation.mjs`                       | 确定性资产配置与压力引擎             |
| `lib/discipline.mjs`                       | 权重偏离和新增资金比较               |
| `lib/assistant.mjs`                        | 问答与引用检查                       |
| `lib/model-provider.mjs`                   | 服务端模型传输                       |
| `lib/retrieval.mjs`、`scripts/retrieve.py` | 本地资料检索适配                     |
| `data/sources.json`                        | 来源定位与简要参考说明               |
| `test/`                                    | 金额、边界、问答、检索与 HTTP 测试   |
| `docs/`                                    | 计算、来源、模型、检索和验收说明     |
