## 原文与模型

研究覆盖《资产配置行动指南》十章及前言、结语，共628段；另外回读相关播客、文字稿、文章与问答。原始文本质量与说话人局限见 [来源说明](SOURCES.md)。

真实模型使用 DeepSeek 官方接口、`deepseek-flash`、非思考模式。除连通探针外，代表问题包括短期首付、应急月数是否普适、黄金个人比例、陈鹏发言归属、货币基金收益口径、创业与锁定期限、软件比例归属与日常现金流。八条验收回答均保留了带真实出处的模型段落：五条整份通过应用检查，三条只保留通过检查的段落。已按原文人工复核这些保留段落；这些数量只描述本次样本，不是通用准确率。

计算情景的金额、权益约束原因及模板关系由程序直接呈现。模型仅接收定性规划背景与相关原文，辅助解释框架和核对方向。最后一次个人情景浏览器验证中，程序计算说明正确，生成回答未通过核验时显示原文检索结果。

检索默认采用关键词、主题改写和精读锚点，并支持显式复用现有向量。开发集与留出集、资源开销及当前检索局限见 [检索评估](RETRIEVAL.md)。复杂表达可能只检出部分相关段落；模型无法补齐未检出的事实。引文存在检查也不等于完整语义得到自动证明。

## 独立审查与 API 检查

独立 AI 审查分别覆盖计算/界面/API与模型/检索数据流。相关发现已修复并回归核验：请求并发、规划版本往返、失败导入原子性、跨规划状态、压力更新、大额金额、数字边界、未知说话人归属及自然提及识别。

合成慢请求探针确认模型请求最多并发2个，超额返回429。静态白名单不暴露模型模块、数据库或环境文件；HTTP接口验证来源、JSON类型和长度。检索进程使用只读数据库，环境不继承模型凭据。普通问答不附带家庭底账；情景解释由服务端重新计算，不采信客户端自称的计算结果。
